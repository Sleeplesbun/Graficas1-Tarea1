Instrucciones para correr el proyecto:

  Para ejecutar el proyecto localmente, abre una terminal o consola en la carpeta raíz del repositorio y ejecuta los siguientes comandos en orden:
  
  Instalar las dependencias necesarias:
    npm install
  
  Iniciar el servidor de desarrollo:
    npm run dev

  Abrir en el navegador con la dirección que aparece en el terminal (normalmente http://localhost:5173)
